# Поздравление с Audi A6 C6 (v2, с PNG)

Все файлы лежат в ОДНОЙ папке:
  index.html
  style.css
  script.js
  car.png   <- твоя картинка (добавь сам)

Требования к car.png: вид строго сбоку, прозрачный фон, обрезка вплотную к машине (без пустых полей).
Если капот смотрит влево, поставь facesRight: false в script.js.

Подгонка колёс и фары: открой index.html?debug=1 и поправь числа в CONFIG.car.
Тексты: блок CONFIG в начале script.js.

GitHub Pages: загрузи эти 4 файла в корень репозитория, затем Settings -> Pages -> Branch main, папка / (root).
